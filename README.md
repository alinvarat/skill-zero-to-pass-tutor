# zero-to-pass-tutor

Tutor a zero-foundation learner for an exam or technical topic using worked examples first, single-step pacing, single-twist difficulty scaling, problem-recognition drills, active review quizzes, and terminal-safe math.

This is an agent skill: `SKILL.md` tells an AI coding agent such as Claude Code when to use it and which steps to follow.

## Install

```bash
git clone https://github.com/alinvarat/skill-zero-to-pass-tutor.git ~/.claude/skills/zero-to-pass-tutor
```
